# Tableau Dashboard Specification

## Dashboard: AML Transaction Risk Monitoring

Sheets:
1. Risk Tier Distribution
2. Alert Volume by Country Risk
3. KYC/KYB Completeness by Portfolio
4. High-Risk Transaction Detail

Filters:
- Risk tier
- Portfolio
- Country risk score
- Cross-border flag
- Transaction amount

Purpose:
Track transaction alerts and KYC/KYB completeness while making data-quality gaps visible.
