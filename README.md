# AML Transaction Risk Monitoring & Alert System

A portfolio project using 50,000 simulated transaction records to demonstrate AML-style transaction monitoring, rule-based alerts, logistic-regression risk scoring, SQL data remediation, and dashboard specifications.

## Stack
Python, SQL, Pandas, Scikit-learn, Tableau, Excel

## Structure
- `data/` simulated transaction and portfolio datasets
- `src/risk_model.py` logistic regression example
- `sql/` alert and four-source remediation queries
- `reports/` Tableau dashboard specification

All records are simulated for demonstration and do not represent real customers or financial institutions.
